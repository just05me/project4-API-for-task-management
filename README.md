# Список задач (To-Do List API)

Этот проект представляет собой REST API для управления списком задач, созданный с использованием FastAPI и MySQL. API позволяет добавлять, просматривать, редактировать и удалять задачи, которые хранятся в базе данных MySQL.

## Структура проекта

- makingToDoLists.py: Основной файл с кодом API, содержащий логику подключения к базе данных и endpoints для работы с задачами.
- fastapivenv/: Виртуальное окружение, содержащее все необходимые библиотеки Python.

## Требования

- Python 3.8 или выше
- Локально запущенный сервер MySQL с базой данных tasks_db

## Установка

1. Склонируйте репозиторий:
   ```
   git clone <URL-репозитория>
   cd <директория-репозитория>
   ```

2. Активируйте виртуальное окружение:
   ```
   source fastapivenv/bin/activate  # Для Linux/Mac
   fastapivenv\Scripts\activate     # Для Windows
   ```

   Примечание: Все необходимые библиотеки (fastapi, mysql-connector-python, и другие зависимости) находятся в виртуальном окружении fastapivenv.

3. Настройте MySQL:
   - Убедитесь, что сервер MySQL запущен.
   - Создайте базу данных tasks_db:
     ```
     CREATE DATABASE tasks_db;
     ```
   - При необходимости измените учетные данные в makingToDoLists.py (по умолчанию: user="root", password="itsmyfirstlinux").

## Использование

1. Запустите FastAPI сервер:
   ```
   uvicorn makingToDoLists:my_app --reload
   ```

2. Доступ к API:
   - Откройте браузер или используйте инструмент вроде Postman/Curl для взаимодействия с API.
   - Документация API доступна по адресу: http://127.0.0.1:8000/docs (Swagger UI).

3. Доступные endpoints:
   - GET /: Возвращает приветственное сообщение.
   - POST /add_task?task_text=<текст_задачи>: Добавляет новую задачу.
   - GET /tasks: Возвращает список всех задач.
   - PUT /change_task?task_id=<id>&new_text=<новый_текст>&new_done=<0_или_1>: Обновляет задачу по ID.
   - DELETE /delete_task?task_id=<id>: Удаляет задачу по ID.

   Пример запроса (с использованием curl):
   - Добавить задачу:
     ```
     curl -X POST "http://127.0.0.1:8000/add_task?task_text=Купить%20молоко"
     ```
   - Получить все задачи:
     ```
     curl -X GET "http://127.0.0.1:8000/tasks"
     ```

## Схема базы данных

API создает таблицу my_tasks в базе данных tasks_db со следующей структурой:

```
CREATE TABLE my_tasks (
    id INT AUTO_INCREMENT PRIMARY KEY,
    task_text VARCHAR(255),
    done INT
);
```

- id: Уникальный идентификатор задачи.
- task_text: Текст задачи (до 255 символов).
- done: Статус задачи (0 — не выполнена, 1 — выполнена).

## Настройка

- База данных: Настройте параметры подключения к MySQL в makingToDoLists.py (host, user, password, database), если они отличаются от указанных.
- Текст задач: Ограничение на длину текста задачи — 255 символов (настраивается в схеме таблицы).

## Примечания

- Виртуальное окружение fastapivenv содержит все зависимости, поэтому установка дополнительных библиотек не требуется, если вы не добавляете новый функционал.
- Убедитесь, что сервер MySQL работает и база данных tasks_db создана перед запуском API.
- В коде есть небольшая опечатка в последней строке (return resul вместо return result). Рекомендуется исправить:
  ```
  return result
  ```
